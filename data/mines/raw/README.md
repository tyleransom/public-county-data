# Data Source

Data is downloaded first as a CSV from Homeland Infrastructure Foundation-Level Data (HIFLD). The URL is https://hifld-geoplatform.hub.arcgis.com/pages/hifld-open after which the user should enter "Mines" and then select "Mines and Mineral Resources" and then click the "Download" button under the "CSV" option.

If the file gets opened in Excel before being read into statistical software, the date variables may become unusable.
